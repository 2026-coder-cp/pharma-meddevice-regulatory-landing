# Life Sciences Engineering Landing Page

A responsive, single-page website covering pharmaceutical packaging, medical devices, and regulatory science.

## Deployment
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then **Save**.
4. Visit https://2026-coder-cp.github.io/pharma-meddevice-regulatory-landing/ after GitHub finishes deployment.

The site is self-contained in `index.html` and needs no build step or external dependencies.

FDA, ISO, ASTM, and ICH are referenced as text for informational context; no endorsement or certification is implied.
